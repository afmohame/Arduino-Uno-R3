# Introduction to the Arduino Uno R3
The Arduino Uno R3 is a microntroller with which we can controll various components. It is a small and compact microcontroller that has 6 analog pins, 14 digital pins, 5V and 3.3V output pins, reset button and pin and more. In this artikel I will be discussing the ins and out of the Arduino Uno R3 and its capabilities to extend my knowledge about it and also for furthur reference in the projects to come.
